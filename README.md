### 🛡️ AIWAF - AI-Based Web Application Firewall

My Final Year Project focused on combining **machine learning, web security, and real-time HTTP traffic analysis**.

Current work includes:

- 🔍 HTTP request feature extraction
- 🧠 Machine learning-based attack detection
- 🛡️ SQLi, XSS, SSRF, Path Traversal & other attack patterns
- 🌐 REST API, GraphQL & modern web traffic
- ⚡ Real-time middleware / reverse-proxy architecture
- 🚨 Anomaly detection for unknown threats

**Goal:** Build a lightweight intelligent security layer capable of detecting malicious web traffic before it reaches the application.
